# AGENTS.md — Cadence

Cadence is a Congressional App Challenge 2026 entry. It is a 60-second daily voice check for iOS and
Android. The user describes a picture out loud. On-device Whisper transcribes the recording with
timestamps. The app computes nine speech features, scores them with a logistic regression trained
offline in Python, compares them with the user's personal baseline, and shows a screening tier:
**Typical / Worth watching / Talk to a doctor**.

**Current status and the prioritized task list are in [`HANDOFF.md`](HANDOFF.md). Read it first.**
The exact feature definitions and data contracts are in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Non-negotiables

1. **Never present a result as a diagnosis.** Every result screen and the PDF carry "screening
   estimate, not a diagnosis". The app is an educational research prototype, not a medical device
   (FDA treats screening/diagnostic apps as devices).
2. **Keep the `trained` flag honest.** `app/assets/model.json` is currently a synthetic demo model
   (`"trained": false`), because DementiaBank access has not been granted. The UI must say "demo
   model" wherever a result appears. Set `trained: true` only for a model fitted entirely on real
   corpus data. `training/train.py` enforces this.
3. **A demo model must never push anyone to "Talk to a doctor".** `decideTier` in
   `app/src/scorer.ts` enforces these invariants, and `app/src/__tests__/tier.test.ts` tests them:
   - never escalate on a single bad day
   - an untrained model alone can never yield `doctor`
   - drift cannot contribute while the baseline is still building
4. **TypeScript and Python must compute identical features.** `app/src/shared/feature_spec.json` and
   `lexicon.json` are the single source of truth for both `app/src/features.ts` and
   `training/features.py`. If you change a feature definition:
   - bump `spec_version`
   - update both implementations and `docs/ARCHITECTURE.md`
   - regenerate the golden fixtures (`training/export_fixtures.py`)
   - retrain `model.json`

   `app/src/__tests__/parity.test.ts` must stay green. Parity is not validity: the audio-energy
   heuristic still needs testing across microphones, background noise, and real speech.
5. **Privacy.** Audio never leaves the device. There is no analytics and no network use except the
   one-time Whisper model download.
6. **Audience is adults aged 50–85, some worried about their memory.** Copy should be calm, plain,
   hedged, and non-alarming:
   - body text ≥ 17 pt
   - touch targets ≥ 56 pt
   - tiers are never shown by color alone
   - light and dark mode both work

## Gotchas you will hit

- **Expo SDK 57 changed many APIs.** Read `app/AGENTS.md` and the versioned docs at
  https://docs.expo.dev/versions/v57.0.0/, and check the installed sources in `app/node_modules`
  rather than relying on memory. `expo-audio` 57 provides raw PCM through `useAudioStream`. That is how
  Android gets WAV audio at all.
- **Expo 57 prebuild recreates native folders by default.** For incremental config/artwork updates,
  use `npx expo prebuild --no-clean`; otherwise Pods and native build outputs are removed and must
  be regenerated. Native folders are generated and gitignored, not the source of truth.
- **Xcode 27 builds need scene support on iOS 27.** Keep `expo-build-properties` with
  `ios.enableSceneSupport: true` in `app.json` (supported by Expo 57.0.23+). Without it UIKit aborts
  startup before the app opens. The generated AppDelegate uses `ExpoReactNativeFactoryProvider`;
  the scene manifest references `EXExpoAppSceneDelegate`.
- **whisper.rn's `package.json` `exports` map has no `"."` entry.** Use `'whisper.rn/index'`.
  `tsconfig.json` maps that import to `lib/typescript/index.d.ts`; iOS and Android Metro exports pass.
- **TypeScript 6 defaults `types` to `[]`.** Test files that need Node globals use
  `/// <reference types="node" />`. Do not add `node` to `tsconfig.json`, so RN code never sees Node
  APIs.
- **Expo typed routes are off** (`app.json` → `experiments.typedRoutes: false`), so plain string hrefs
  are correct.
- **whisper.cpp segment `t0`/`t1` are in centiseconds.** With `maxLen: 1`, each segment is one BPE
  token, and `segmentsToWords` merges tokens using the leading-space rule.
- **Android builds need JDK 17–21.** The `java` on this machine's PATH is 26, which is too new for
  Gradle. Use `JAVA_HOME=/Users/gupta/Library/Java/JavaVirtualMachines/jbr-21.0.11/Contents/Home`.
- `ffmpeg` is not installed. The training code decodes MP3 with `soundfile`, falling back to macOS
  `afconvert`.
- If Python Whisper fails while initializing Metal, use `CADENCE_WHISPER_CPU=1`. This runs the
  same transcription parameters on CPU and was used to regenerate the V2 reference fixture.

## Conventions

- 2-space indent, single quotes, semicolons, the `@/…` import alias, and strict TypeScript without
  `any`.
- Tests go in `app/src/__tests__/*.test.ts(x)` and `training/tests/`. New logic comes with tests.
- Do not commit `training/.venv`, `training/models/` (the 74 MB Whisper binary), `training/data/`,
  `training/outputs/`, or `app/ios` / `app/android`. They are already gitignored.
- Owner intent from the original plan: the student (repo owner) meant to write the tier logic
  (`decideTier`) and choose the pause-gap threshold (`pause_gap_s`) themselves, as learning exercises.
  Keep those two pieces small and readable, and do not redesign them without the owner.
